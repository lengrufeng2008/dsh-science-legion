DSH SCIENCE LEGION · v0.2.0

Verified science,
not agent theater.

A command layer for tiered multi-agent campaigns in math, physics, astronomy, engineering, and biomedical evidence. One commander, a shared blackboard, independent lines of attack, a verifier that can say no, and a token budget written down before anyone spawns.

A six-agent squad's first catch was an error in its own benchmark.
The answer key said the fourth-order pendulum value at 1 rad was 1.066315375. The independent verifier showed that is actually the sixth-order truncation T6 = 1.066315375434…. The real fourth-order value is T4 = 3275/3072 = 1.066080729…. The formula survived; the key was corrected.

Why this exists

Frontier models are good at producing plausible physics. Plausible is not verified. I wanted a science tool judged by verified claims per token, not by how many agents it can spawn. The first six-agent run immediately caught a bad answer key — mine. That is the product working.

What is in the bundle

COMMAND

Squad 6 → Platoon 24 → Company 96 → Legion 384–1000. The Legion tier is a budgeted, untested design target, not a default.

DOMAINS

Math, physics, astronomy, engineering design checks, and biomedical evidence appraisal. Biomedical is evidence review, not medical advice.

VERIFY

A separate verifier with claim-only input, an evidence table, reproduction, falsification, and provenance. Consensus is not proof.

Tactics

WOLF PACK independent packs with different methods, no cross-talk before submission.
FLANK reach the claim through a neighbouring field, limit, or dual formulation.
PINCER two independent methods must agree; disagreement stays unresolved.
SIEGE rounds with a blackboard, not one giant fan-out. Keep 20–30% of tokens for verification.

The fourth-order pilot, in numbers

T/T0 = 1 + θ0²/16 + 11 θ0⁴/3072 + 173 θ0⁶/737280 + O(θ0⁸)
T    = 4√(L/g) K(sin(θ0/2))

θ0 = 1 rad:
exact T/T0 = 1.066334245579963…
T4         = 3275/3072 = 1.066080729166…
T4 - exact = -2.53516413296e-4   (-0.0238%)
old key    = 1.066315375          ← this is T6, not T4

Exact rational series, AGM/Decimal, tanh-sinh quadrature, and RK4 agree. The answer key was wrong; the formula was not.

The estimator scales that pilot: node scripts/estimate-campaign.mjs --agents 24 → about ¥7.27 with 25% coordination overhead. It is a planning number, not a quote.

Measured cost: ¥1.4543 for the six agent sessions (110 calls; 5.79M cache-read, 155.6k uncached input, 295.7k output). Orchestrator/main session excluded. ¥1.45 per verified answer for this run — not a linear price for 1000 agents.

What it does not prove

  • It does not solve an open problem. The pilot is a known-answer problem.
  • It has not run 24, 96, or 1000 agents. Six is the largest validated squad.
  • Only the six-agent pilot cost is measured (¥1.4543, agent sessions only). No 24/96/1000-agent cost model exists.
  • The ideal-pendulum assumptions are unchecked against an apparatus.
